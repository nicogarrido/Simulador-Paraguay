# Simulador MIP Paraguay — material de formación

Material del curso sobre el simulador de impacto construido sobre la Matriz
Insumo-Producto de Paraguay 2024.

**Sitio web:** https://USUARIO.github.io/Simulador-Paraguay

## Cómo trabajar en este repositorio

Ver [`GUIA-INICIO.md`](GUIA-INICIO.md).

En resumen: se escribe en archivos `.qmd` (Markdown), se ejecuta `quarto render`
para generar el HTML en `docs/`, y se sube con GitHub Desktop.

## Estructura

```
├── _quarto.yml        configuración del sitio
├── estilos.scss       identidad visual
├── index.qmd          portada
├── guia-de-estilo.qmd referencia de formato
├── recursos/          imágenes y archivos auxiliares
└── docs/              sitio HTML generado — no editar a mano
```
